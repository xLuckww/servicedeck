# 素材来源与授权

宣传片用到的外部素材都记录在这里（设计文档第 8、10 节）。发布时把本文件内容整理进 B 站简介。

## 音乐与音效
全部由 `video/audio.py` 用代码合成（numpy 加法合成与噪声整形），**没有使用任何外部音频素材**。

## 字体
- 思源黑体 Noto Sans SC（Adobe / Google），SIL Open Font License 1.1，来源 https://github.com/google/fonts/tree/main/ofl/notosanssc
- JetBrains Mono（JetBrains），SIL Open Font License 1.1，来源 https://github.com/google/fonts/tree/main/ofl/jetbrainsmono

仓库里的 `assets/fonts/*.woff2` 是按片中用到的字裁出的子集，按 OFL 要求改名为 SD Promo Sans / SD Promo Mono，授权文本见同目录的 `*-OFL.txt`。

## 图标
- GitHub 标志：来自 Simple Icons（CC0），仅用于标明作者的 GitHub 账号名。

## 其他
画面中的界面、终端输出、服务名称均为按 ServiceDeck 真实界面重绘的模拟内容；结尾数字与测试结果为 2026-09-29 的真实统计。
